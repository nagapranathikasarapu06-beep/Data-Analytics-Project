
# Sales & Customer Analytics Dashboard

## Project Overview
An end-to-end retail sales analytics project using
Excel, Python, Power BI, and DAX.

## Objectives
- Analyze sales and profitability.
- Understand customer purchasing behavior.
- Compare regional and product performance.
- Build an interactive Power BI dashboard.

## Tools & Technologies
- Microsoft Excel
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Power BI
- DAX

## Project Workflow
1. Data inspection and initial cleaning in Excel.
2. Data cleaning and exploratory data analysis in Python.
3. KPI development and dashboard creation in Power BI.

## Project Status
Excel preparation completed.
Python EDA and Power BI dashboard are pending.
